# 针迹

王虹证明的数学论文与循序学习路径。站点用 Next.js 做成可读的八关路线：从挂谷针问题，经维数与经典 Kakeya 技术，走到 Wang–Zahl 三维挂谷三部曲。

## 本地运行

```bash
npm install
npm run dev
```

开发服务器默认在 [http://127.0.0.1:43147](http://127.0.0.1:43147)。

生产构建：

```bash
npm run build
npm run start
```

## 内容结构

- `/` 首页：三维管场与入口
- `/papers` 王虹（及合作者）的关键论文，按挂谷 / 姊妹问题 / 调和分析 / 导读分组
- `/path` 八关学习路径
- `/path/[slug]` 每一关的概念、步骤、阅读、自测
- `/daily` 12 周数学基础与练习的每日行动库（60 项，含知识、练习、完成标准）

进度标记存在浏览器 `localStorage`，无需账号。

## 说明

三维挂谷集合猜想由 Hong Wang 与 Joshua Zahl 共同证明。本仓库只整理公开文献与学习顺序，不替代原论文。
